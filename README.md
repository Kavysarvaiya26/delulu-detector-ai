🧠 Delulu Detector AI

Delulu Detector AI is a web-based AI project developed for a hackathon.
It analyzes unrealistic goals set by users and converts them into realistic, achievable action plans.

🚀 Problem Statement

Students often set unrealistic goals influenced by social media and fake motivation.
This leads to burnout, frustration, and loss of confidence due to lack of honest feedback.

💡 Solution

Delulu Detector AI provides:

A Delulu Score (0–100) to measure unrealistic expectations

Honest explanations instead of generic motivation

A realistic, step-by-step plan to achieve goals

🛠️ Google Technology Used

Google Gemini API
Used for natural language understanding, goal analysis, and plan generation.

🖥️ MVP

Simple web-based interface

User enters a goal and receives AI-generated analysis

Deployed using GitHub Pages
